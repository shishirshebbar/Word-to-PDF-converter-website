# Word to PDF Converter Website

## About the Project

This project is a web application built using the MERN stack that allows users to convert Word documents into PDF files. Users can upload a Word file, and the system processes it to generate a downloadable PDF. The application is designed to be simple and efficient, providing a smooth user experience for file conversion.

---

## Clone the Repository

To get a local copy of the project, open your terminal and run:

```bash
git clone https://github.com/shishirshebbar/Word-to-PDF-converter-website.git
cd "Word to PDF Converter"
```

## Run Instructions

1. Backend

Navigate to the backend directory, install dependencies, and start the server:

```bash
cd Backend
npm install
npm start
```

The backend server will start on the port configured in your project (check your backend config or .env).

2. Frontend

Navigate to the frontend directory, install dependencies, and start the application:

```bash
cd Frontend
npm install
npm run dev
```

The frontend will start (commonly at http://localhost:3000 or the port shown in the terminal). Connect it to the backend as configured in your frontend environment settings.
